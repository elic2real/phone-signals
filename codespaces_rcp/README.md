# Codespaces RCP — Enforcement Setup Trunk

This package contains **schema + validation + framework scaffolding** for future PC2 discovery outputs.

Scope of this trunk:
- JSON schemas for agreed artifact names
- Artifact / ownership / dependency validators
- Universal analyzer scaffolding (non-judging)
- Gold-case manifest framework
- Promotion gate framework (precondition checks only)
- Intervention basis contract
- Report loaders/parsers

Out of scope in this trunk:
- No candidate judging
- No champion/challenger claims
- No reranking/archetype conclusions
- No promotion execution on missing outputs
